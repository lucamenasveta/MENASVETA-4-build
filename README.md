# MENASVETA-4-build

**Andaman Breath**, a responsive single-page site built for AME 112.

A plain guide to freediving the Andaman coast: where to go, when to go, and how
to stay safe doing it.

## Structure

- `index.html` — semantic markup: `header`, `nav`, `main` with four content
  sections, and `footer`.
- `style.css` — mobile-first styles. CSS Grid sets the page-level layout with
  named areas, Flexbox handles the navigation bar and the card row, and two
  media queries (600px and 900px) widen the layout on larger screens.
